CONNECT STORE — versão PWA offline

Arquivos:
- index.html: aplicativo completo
- manifest.json: instalação como PWA
- sw.js: cache/offline
- logo.png: identidade visual Connect Store

Para usar: hospede esta pasta em um servidor HTTPS (GitHub Pages, Netlify, Vercel ou similar) e abra o link no Chrome. Após o primeiro carregamento, os arquivos ficam disponíveis offline.

Dados são armazenados localmente no navegador/dispositivo. Use Backup regularmente para gerar um JSON de segurança.
